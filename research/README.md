1. Review and redact the research PDFs.
2. Copy the approved PDFs into `research/documents/`.
3. In `index.html`, replace each placeholder paragraph with its corresponding PDF link.
4. Confirm filenames match the links exactly.
5. Commit the `research/` folder to the `main` branch.
